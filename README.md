# Invoicle — landing page

Marketing site for **[@Invoiclebot](https://t.me/Invoiclebot)**, a Telegram bot
that creates professional PDF invoices in about ten seconds.

🌍 **Live:** https://tahbenab-ops.github.io/Invoicle/

## What the bot does

- Professional PDF and image invoices, A4 and A5
- Five languages (English, فارسی, العربية, Türkçe, Русский) with full RTL support
- Your logo and product photos on every document
- Customer book with purchase history and outstanding balance
- Inventory tracking with low-stock alerts
- Income, expenses and profit reports with Excel export
- 20 free invoices every month

## This repository

Static output only: 5 languages × (landing + privacy + terms), plus
`sitemap.xml`, `robots.txt`, a PWA manifest and a 404 page.
GitHub Pages serves it directly from `main`.

The site is generated by `site/build.py` in the bot's source repository —
edit the copy there, not the HTML here.
